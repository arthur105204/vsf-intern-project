# ROADMAP

## Phase 1 — Data & Baselines (week 1)
- Tasks: download dataset, preprocess, exploratory analysis, implement popularity baseline
- Deliverables: `data/processed/` samples, baseline metrics, small EDA notebook

## Phase 2 — Two-Tower Prototype (week 2)
- Tasks: implement ID-only two-tower, train, evaluate
- Deliverables: training code, model checkpoints, evaluation table

## Phase 3 — Features & Corrections (week 3)
- Tasks: add BOW history, item metadata, test LogQ correction, compare negatives
- Deliverables: ablation results, updated metrics table

## Phase 4 — Indexing & Serving (week 4)
- Tasks: export item embeddings, build ANN index (optional), implement demo/API
- Deliverables: item embeddings, index files (git-ignored), demo code

## Phase 5 — Report & Wrap-up (week 5)
- Tasks: finalize experiments, write conclusions, record limitations and next steps
- Deliverables: final report, cleaned notebooks, README updates
