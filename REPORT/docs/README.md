# Documentation Index

Use this folder as the reading order for the project docs.

1. [Project PRD](../PRD.md) — project intent, goals, scope, and non-goals.
2. [Dataset Notes](../DATASET.md) — source, raw files, and data storage policy.
3. [Technical Design](TECHNICAL_DESIGN.md) — data pipeline, model, retrieval serving, and limitations.

- [Project PRD](../PRD.md): the product-style overview of what the prototype should demonstrate.

- [Technical Design](TECHNICAL_DESIGN.md): the implementation architecture and runtime flow.
- [Experiment Plan](EXPERIMENT_PLAN.md): the evaluation roadmap and comparison matrix.
